# PIXEL ROYALE — пиксельная battle-royale RPG

Вся игра — в **одном файле `index.html`**. Никаких зависимостей, бэкенда и базы данных:
графика рисуется процедурно на canvas, прогресс хранится в `localStorage` браузера.

## Как играть

- **WASD** — движение, **ЛКМ** — базовая атака, **1…6** — скилы, **Tab** — таблица живых, **Esc** — пауза, **M** — звук
- **200 видов врагов** (5 биомов × 8 видов × 5 тиров) с разными архетипами: стрелки-духи, танки-големы,
  насекомые с выводком; сложность растёт со стадиями зоны.
- **500 перков** (10 тиров + 12 билдообразующих: пронзание, крит-взрыв, шипы, стеклянная пушка…),
  за уровень — выбор 1 из 3.
- **Скилы генерируются случайно** (стихия × форма × редкость × сила × КД). Если слоты заняты —
  модалка замены с авто-выбросом через 5 секунд.
- **Мета-прогрессия без RNG**: за матч дают осколки (#1 = 5, топ-3 = 3, топ-10 = 2, участие = 1,
  +1 за каждые 50 убийств); каждые 6 осколков — +1 слот скила навсегда (максимум 6). Плюс бестиарий:
  открыто видов X/200.
- **Battle royale на 50 бойцов**: зона сужается 8 стадий с ускорением к финалу, боты фармят,
  сходятся к центру и воюют друг с другом.

## Локальный запуск

Просто откройте `index.html` в браузере — или, если браузер блокирует файл по двойному клику:

```
python -m http.server 8000
```

и откройте http://localhost:8000

## Запуск на сервере, чтобы друзья могли подключиться

Игра — статический HTML-файл, сервер отдаёт его как есть. Матч у каждого игрока свой:
49 ботов против вас. Друзья, открывшие ссылку, играют каждый в свою игру (общего
мира нет — для этого нужен WebSocket-бэкенд).

**1. Локальная сеть (LAN) — за минуту, без интернета:**
```
python -m http.server 80 --bind 0.0.0.0
```
Друзья заходят на `http://ВАШ_IP/` (IP узнайте через `ipconfig`/`ifconfig`).
Порт 80 должен быть открыт в брандмауэре.

**2. GitHub Pages — бесплатно, навсегда, публичная ссылка:**
- Создайте репозиторий на github.com, загрузите `index.html`.
- Settings → Pages → Branch: `main` → Save.
- Ссылка: `https://ваш-ник.github.io/имя-репозитория/` — кидайте друзьям.

**3. Netlify Drop — за 30 секунд:** зайдите на app.netlify.com/drop и перетащите
папку с `index.html` — получите публичный HTTPS-адрес.

**4. itch.io** — запакуйте `index.html` в zip, создайте проект (тип HTML5),
загрузите архив — получится страница игры с комментариями.

**5. VPS (полный контроль):** любой nginx/Apache, корень указывает на папку с файлом.
Если позже захотите настоящий мультиплеер — на VPS же поднимается Node.js-сервер
с WebSocket (сейчас его роль играют 49 ботов).

Прогресс (осколки, слоты, бестиарий) хранится в `localStorage` браузера игрока.
